🐍 Python MCQ Quiz Generator

Learn • Practice • Improve

An interactive Python-based quiz application designed to help students practise programming concepts through multiple-choice questions (MCQs).

The application provides topic-wise quizzes, automatic evaluation, countdown timers, result storage and performance feedback through a simple user interface.

📌 Introduction

The Python MCQ Quiz Generator is an educational application developed using Python. It allows students to select programming topics, attend quizzes, submit answers and view their performance.

The main objective is to make Python learning more interactive, organized and effective.

🧮 Score Calculation

The application calculates the percentage based on the number of correct answers.

Formula:

Percentage = (Correct Answers / Total Questions) × 100

Example:

Correct Answers = 5

Total Questions = 6

Percentage = (5 / 6) × 100 = 83.33%

📂 Data Storage

The application uses CSV files to maintain records.

students.csv – Stores student details.

quiz_results.csv – Stores quiz attempt results.
